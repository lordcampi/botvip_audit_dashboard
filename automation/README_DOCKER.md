# BotVIP Daily AI Reporter - Docker deployment\n\nThis Docker setup runs the reporter as an independent one-shot container.\n\nSafety design:\n- It does not use or restart the main BotVIP Docker Compose project.\n- It bind-mounts the SQLite database read-only.\n- It writes reports only under this reporter project directory.\n- The application itself also opens SQLite in read-only/query-only mode.\n\nDefault DB mount expected on Vultr:\n\n```text\n/opt/botvip/data/trading_bot.db -> /data/trading_bot.db:ro\n```\n\nIf your BotVIP DB is mounted elsewhere, edit `docker-compose.reporter.yml` before running.\n\n## Build\n\n```bash\ncd /opt/botvip_audit_dashboard\nsudo docker compose -f docker-compose.reporter.yml build\n```\n\n## Dry run\n\n```bash\ncd /opt/botvip_audit_dashboard\nsudo docker compose -f docker-compose.reporter.yml run --rm reporter python daily_ai_report.py --window daily --output reports --dry-run\n```\n\n## Generate report\n\n```bash\ncd /opt/botvip_audit_dashboard\nsudo docker compose -f docker-compose.reporter.yml run --rm reporter\n```\n\n## Cron at 5:00 a.m. Colombia / 10:00 UTC\n\nUse root crontab if Docker requires sudo:\n\n```bash\nsudo crontab -e\n```\n\nAdd:\n\n```cron\n0 10 * * * cd /opt/botvip_audit_dashboard && /usr/bin/docker compose -f docker-compose.reporter.yml run --rm reporter >> logs/daily_ai_report_docker_cron.log 2>&1\n```\n
